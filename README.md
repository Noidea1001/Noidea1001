## Architecture

I prefer separating applications into clear layers so that the frontend, backend, business logic, and database can evolve independently.

```text
                         CLIENT
                           |
                           | HTTP / JSON
                           v
                    ┌───────────────┐
                    │   REST API    │
                    └───────┬───────┘
                            |
                  ┌─────────┴─────────┐
                  |                   |
            Authentication       Business Logic
                  |                   |
                  └─────────┬─────────┘
                            |
                            v
                    ┌───────────────┐
                    │ ORM / Data    │
                    │    Access     │
                    └───────┬───────┘
                            |
                            v
                    ┌───────────────┐
                    │   DATABASE    │
                    └───────────────┘
```
